# Animation clips

`ual_clips.glb` is a small part of Quaternius's Universal Animation Library (UAL), dedicated to the public domain under CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). It holds the library's skeleton on Godot's humanoid bone names and 14 clips, with no mesh and no root motion. The full library is at https://quaternius.itch.io/universal-animation-library.
