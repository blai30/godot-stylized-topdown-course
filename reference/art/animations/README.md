# Animation clips

`ual1_standard.glb` is Quaternius's Universal Animation Library (Standard), renamed from the pack's `UAL1_Standard.glb` to follow the project's file naming, from https://quaternius.itch.io/universal-animation-library, dedicated to the public domain under CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). It is the file in the pack's `Unreal-Godot` folder with root motion disabled.
