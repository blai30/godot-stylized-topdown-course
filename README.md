# Hand-Made Top-Down

A beginner course that teaches you to build, entirely by hand, a reusable Godot game template with a stylized top-down look. Working name.

| Folder | Contents |
|---|---|
| `site/` | The course website (Astro and Starlight). |
| `reference/` | The course's own build of the template, made by following the lessons. It proves every step works and provides the screenshots and solution code. |
| `docs/` | The course spec, phase reports, and the target-look reference images. |
| `tools/verification/` | Tooling that performs lessons in Godot and Blender, captures screenshots, and checks the site. |

Binary files are stored with Git LFS; run `git lfs install` once before cloning.
