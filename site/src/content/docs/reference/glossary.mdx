---
title: Glossary
description: Every term the course uses, in plain language.
---

Terms are in alphabetical order. Lessons link here the first time they use a term.

## Albedo

The plain color of a surface before any light falls on it. A material's **Albedo** section sets it, as a color, a texture, or both multiplied together; in a shader you set it with `ALBEDO`.

## Assembly

A compiled library of code. Building your C# scripts produces one assembly for the whole project, named after the project, which Godot loads when the game starts.

## Bevel

A narrow slanted face that replaces a sharp edge. Real objects never have perfectly sharp edges, so small bevels catch light along the edge and make a model read as solid.

## Blockout

A first, rough version of a model made of big simple shapes, to settle its size and silhouette before any detail.

## Branch

A line of commits in Git. A new repository has one, here named `main`. Later you can make another branch to try an idea without touching `main`, and merge it back if it works.

## C#

The programming language this course uses for game code. You write it in your IDE, and Godot's .NET edition runs it.

## Class

In C#, the description of a kind of object: its data (properties and fields) and what it can do (methods). Each Godot script is a class, such as `CameraRig`, that extends a node type, such as `Node3D`.

## Color ramp

A short row of colors for one material, from its shadow to its highlight, stepping evenly in value. Lesson 7's palette gives each material a ramp of four.

## Commit

A saved version of your project in Git: a snapshot of every file at that moment, with a short message saying what changed. You can always go back to any commit.

## Convex shape

A shape with no dents or hollows, like a gift wrapped tightly in plastic. Convex collision shapes are cheap for the physics engine and fit rocks and other solid props well.

## Edit Mode

Blender's mode for changing a mesh's vertices, edges, and faces. Press <kbd>Tab</kbd> to switch between Edit Mode and Object Mode.

## Environment

Godot's resource for how a scene's world looks as a whole: the background and sky, the light that comes from the sky, tonemapping, fog, glow, and ambient occlusion. A `WorldEnvironment` node holds it.

## Export

In a Godot script, marking a property with `[Export]` so it appears in the Inspector and its value is saved in the scene. Tunable numbers and references to other nodes are exported, so you can change them without editing code.

## Fragment function

The part of a shader that runs once for every pixel a surface covers on screen, and decides that pixel's color and other surface properties. In Godot it is written `void fragment()`.

## Game engine

A program that does the hard, shared work of a game: drawing 3D graphics, playing sound, reading input, and running physics. You build your game inside it. This course uses Godot.

## Git

A version control system: it records snapshots of your project, called commits, so you can see what changed and go back to any earlier state.

## Git LFS

Git Large File Storage, an add-on for Git that stores big binary files, such as images and Blender files, outside the normal history so the project stays fast to download.

## Gizmo

The colored arrows, rings, and handles Godot and Blender draw on a selected object. Drag them to move, rotate, or scale it.

## glTF

An open file format for 3D models, made for games and apps. A `.glb` file is a glTF model packed into a single binary file. Blender exports it and Godot imports it.

## Hard-surface model

A model of a solid object with firm edges and flat or gently curved faces, such as a rock, a crate, or a wall, as opposed to soft organic forms like skin or cloth.

## Hue

The kind of a color, such as red, yellow, or blue, measured as an angle around a color wheel from 0 to 360 degrees: red at 0, yellow at 60, green at 120, cyan at 180, blue at 240, and magenta at 300.

## Hue shifting

Changing a color's hue as its value changes: toward blue as it darkens and toward yellow as it lightens, the way warm light and cool shadow do. It makes painted colors look alive instead of mixed with black or white.

## IDE

Integrated development environment: a code editor with tools built in, such as autocomplete, error checking, and debugging. Rider and VS Code are the IDEs this course supports.

## Import

What Godot does to a file it finds in the project, such as an image or a model: it converts the file into a form the game loads fast and stores the result in the hidden `.godot` folder. The settings for the conversion live in an `.import` file beside the original.

## Inherited scene

A scene built on top of another scene, its base. It contains everything in the base and can add nodes and change properties, while the base stays untouched. Models imported from Blender are used through inherited scenes, so a re-export updates them without losing your changes.

## Input action

A named move the game reacts to, such as `move_forward` or `zoom_in`, defined in **Project Settings > Input Map** with the keys, buttons, and sticks that trigger it. Code checks the action, never a specific key.

## Inspector

Godot's panel, on the right by default, that shows every property of the selected node or resource and lets you change it.

## Instance

A copy of one scene placed inside another, such as the camera rig inside the meadow. An instance follows its scene: change the scene and every instance changes, except for the properties you overrode on the instance.

## Layer

In a painting program such as Krita, one sheet of an image. Layers stack on top of each other; you can paint on one without touching the others, hide one, or change how it blends with those below.

## Loop cut

In Blender, a new ring of edges cut all the way around a mesh. It adds vertices you can move to shape the model.

## Lossless compression

Compression that makes a file smaller without changing any of its data, such as PNG. Lossy compression, such as the VRAM compression graphics cards use, changes colors slightly to save more space.

## Material

A resource that describes how a surface looks: its color, roughness, and how it reacts to light. A `ShaderMaterial` is a material whose look comes from a shader you write.

## Matrix

A grid of numbers that stores a transform: a position, rotation, and scale together. Multiplying a point by an object's matrix moves the point from the object's own coordinates into the world.

## Mesh

The shape of a 3D object: a set of points (vertices) joined by edges into flat faces. In Godot, a `MeshInstance3D` node shows a mesh in the scene.

## Mipmap

A smaller copy of a texture. A texture with mipmaps has a chain of copies, each half the size of the last, so a surface far from the camera samples a small copy and does not shimmer.

## Modifier

In Blender, an operation added to an object that changes its mesh without destroying the original, such as Bevel. You can change or remove a modifier at any time.

## Namespace

A family name for C# classes, written at the top of a file, such as `namespace TopDownTemplate.Camera;`. It keeps your class names from clashing with classes of the same name elsewhere. In the template, it is the project name followed by the folder under `src` the file sits in.

## Node

The building block of a Godot scene. Every light, camera, mesh, and script lives on a node, and nodes form a tree.

## Normal

The direction a surface faces at a point. Lighting depends on normals, so changing them changes how smooth or sharp a model looks without changing its shape.

## Object Mode

Blender's mode for moving, rotating, and scaling whole objects. Press <kbd>Tab</kbd> to switch between Object Mode and Edit Mode.

## Origin

The single point an object is positioned and rotated around. In Blender it shows as a small orange dot. For props in this course, the origin sits at the center of the model's base, so the model stands on the ground where you place it.

## Orthographic projection

A camera projection that shows every object at the same size wherever it is, with no perspective: parallel lines stay parallel. Its `Size` is the height of the view in meters. Top-down and strategy games use it so the world reads like a tidy map.

## Palette

The fixed set of colors a game's art takes its colors from. In this course it is one small image of flat color swatches, `art/palette/palette.png`, so every model shares the same colors.

## Physics layer

One of 32 groups a physics body can sit on. Each body also has a mask, the layers it collides with. Naming layers in Project Settings, such as `world` and `player`, makes them readable in the Inspector.

## Project

A folder with a `project.godot` file in it. Everything inside the folder belongs to the game, and Godot writes paths to it starting from `res://`.

## Repository

The place Git keeps a project's history: a hidden `.git` folder in the project folder, holding every commit.

## Resource

A piece of data Godot saves and shares, such as a mesh, a material, a texture, or a shader. Several nodes can use the same resource.

## Roughness

How rough a surface is, from 0 (a mirror) to 1 (matte). Rough surfaces spread light out; smooth ones show sharp highlights. In a shader you set it with `ROUGHNESS`.

## Saturation

How strong a color is, from 0% (a gray) to 100% (the purest version of its hue). Natural materials look best muted, at low to middle saturation.

## Scene

A tree of nodes saved as one file, ending in `.tscn`. A level, a player, and a tree are each a scene, and a scene can contain other scenes.

## Script

A file of code attached to a node to give it behavior. In this course scripts are C# files, named after the class inside them, such as `CameraRig.cs`.

## SDK

Software development kit: the tools a programming language needs to build programs. The .NET SDK compiles your C# code.

## Shader

A small program that runs on the graphics card and decides how a surface is drawn. Godot shaders are written in Godot's shading language, a language much like GLSL.

## Shadow map

How Godot draws shadows: the light renders the scene from its own point of view to find what it can reach, and anything it cannot reach is in shadow. Turn it on with the light's **Shadow** setting.

## Smooth shading

Lighting a mesh as if its surface were curved between vertices, instead of flat on every face. It makes a few faces look round.

## Solution

A `.sln` file that lists one or more C# projects for a code editor to open together. Godot creates one beside your `.csproj` file.

## sRGB

The standard color space of ordinary images and screens. Godot reads color textures, such as your palette, as sRGB and converts them before it lights them. In a shader, the `source_color` hint marks a texture as a color texture so Godot does this for you.

## Swatch

One square of flat color in a palette image. Models take a color by pointing their UVs at a swatch.

## Texel density

How many texture pixels (texels) cover one meter of a surface. This course uses 256 pixels per meter everywhere, so textures on different objects look equally sharp side by side.

## Texture

An image a shader reads colors or other values from. Reading from it is called sampling.

## Tonemapping

Turning the light the renderer computes, which can be far brighter than a screen shows, into colors a screen can show. AgX rolls bright colors gently toward white, as film does.

## Triangle budget

The range of triangles a model should use, such as 100 to 400 for a small rock: enough for its shape, and no more. Graphics cards draw triangles, so the count decides how expensive a model is to draw. A budget keeps every model in proportion to how big it appears on screen.

## Uniform

A value a shader reads that you set from outside, in the Inspector or from code. It stays the same for every pixel of a surface, which is where the name comes from.

## UV

Two coordinates, U and V, that say where on a texture each point of a mesh reads its color. They are stored in the mesh.

## Value

How light or dark a color is, from 0% (black) to 100% (the brightest version of its hue and saturation). From a distance, players read shapes by value first.

## Varying

A value a shader's vertex function calculates and hands to its fragment function. Each pixel receives a blend of the values from the vertices around it.

## Vertex

A point of a mesh. Two vertices joined make an edge, and three or more edges around a flat area make a face. In Blender's Edit Mode you select vertices, edges, or faces with the keys 1, 2, and 3.

## Vertex function

The part of a shader that runs once for every vertex of a mesh. In Godot it is written `void vertex()`.

## Weighted normals

Normals calculated so that large faces stay flat and only the small faces around them, such as bevels, carry the curve. It makes a low-poly model look smooth at the edges and crisp across its faces.

## World space

Positions measured in the coordinates of the whole level, rather than relative to one object. A point in world space stays put when you move or turn the object it belongs to.

## X-ray

A Blender view mode that makes the model see-through, so you can select vertices on its far side. Toggle it with Alt+Z.
