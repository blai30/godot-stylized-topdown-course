## The library

The **Universal Animation Library**, UAL, is a set of over a hundred humanoid animations by Quaternius: idles, walks, runs, jumps, fights, and more, released into the public domain (CC0), so you may use it in any game. It comes as a file with a skeleton and its clips and no mesh. The skeleton has its own bone names. After the import in this lesson, both skeletons have the profile's names, such as `LeftUpperArm`, and a track that rotates `LeftUpperArm` rotates yours. That is why a clip from the library plays on your character.

You can download it from `https://quaternius.itch.io/universal-animation-library` (the free pack is enough). To keep this lesson working without a download, the course's reference project includes `art/animations/ual_clips.glb`, a small part of UAL with 14 clips, which you copy into your project.

<Aside type="note" title="Clip names">
The reference file's clips are called `idle`, `walk`, `jog`, and `run`, in lowercase. In the full download, they are `Idle_Loop`, `Walk_Loop`, `Jog_Fwd_Loop`, and `Sprint_Loop`: Godot drops the `_Loop` suffix when it imports them and sets the clip to loop, so you will see `Idle`, `Walk`, `Jog_Fwd`, and `Sprint`. The steps are the same; use your file's names wherever this lesson says `idle`, `walk`, and `run`.
</Aside>

## The library's own BoneMap

The library's skeleton is a different skeleton from yours: it has fingers, eyes, and a jaw you do not. It needs a **BoneMap** of its own, made the same way as yours.

<Steps>

1. Click **Skeleton3D** in the scene tree. Click the **Bone Map** field and choose **New BoneMap**. Open it, click **Profile**, and choose **New SkeletonProfileHumanoid**.

	<Figure
		src={skeleton}
		alt="The Advanced Import Settings window with the library's Skeleton3D selected and its Bone Map field empty."
		caption="The library's skeleton, with no map yet."
	/>

	<Figure
		src={boneMapNew}
		alt="The Bone Map opened with an empty Profile field."
		caption="A new map."
	/>

2. Godot auto-maps. This time it matches **53 of the profile's 56** bones: every bone except `LeftEye`, `RightEye`, and `Jaw`.

	<Figure
		src={autoMapped}
		alt="The Bone Map with a human figure showing green dots for nearly every bone, and the Retarget options with Rename Bones and Make Unique on and Skeleton Name GeneralSkeleton."
		caption="53 of 56 bones mapped."
	/>

</Steps>

Three bones with no match is expected, and Godot may warn about them in the Output panel ("Auto Mapping couldn't guess"). The library has no eyes or jaw, so there is nothing to map, and no clip needs them.

The renamed skeleton is called `GeneralSkeleton`, the same name your character's skeleton has. Every track in the library now reads `%GeneralSkeleton:Hips`, `%GeneralSkeleton:LeftUpperLeg`, and so on: a **unique name** `%GeneralSkeleton` and a bone name. A clip moves whichever skeleton in the scene has that unique name, and your character's has it.

The reference run reads one clip back: `walk` has 52 tracks, and only one of them is a position track, `Hips`. Every other bone only rotates, because a position track on a leg would not fit a character with different leg lengths. The `Hips` position is rescaled by **Normalize Position Tracks**, which lesson 41's import turned on by default, so the walk's bob matches your character's size.

## Make the walking clips loop

A clip ends when it reaches its last frame, unless it is set to **loop**. The walk and the run are cycles, so they must start over. The full UAL's clips already do. The reference file's do not, so set it.

<Steps>

1. In the scene tree of the Advanced window, click `walk`. Its options appear: **Loop Mode**, **Save To File**, and **Slices**.

	<Figure
		src={walk}
		alt="The Advanced Import Settings window with the walk clip selected and its options Loop Mode None, Save To File, and Slices."
		caption="A clip's import options."
	/>

2. Set **Loop Mode** to **Linear**. Do the same for `idle`, `jog`, and `run`.

	<Figure
		src={loopWalk}
		alt="The Advanced Import Settings window with the walk clip's Loop Mode set to Linear."
		caption="Linear: play from the start again when the clip ends."
	/>

3. Click **Reimport**.

</Steps>

## If it does not work

- **The character does not move when a clip plays.** The track paths do not find a skeleton. The skeleton must be named `GeneralSkeleton`, unique in the scene (lesson 41's Rename Bones and Make Unique), and the AnimationPlayer must be a child of the character's root.
- **Some bones are stiff.** The library's map did not cover them. Check the auto-mapping shows 53 bones mapped.
- **The character floats or sinks while walking.** The hips' position track does not fit your character's size. Check that **Normalize Position Tracks** is on in the Retarget options of the library's Skeleton3D, and reimport.
- **The clip plays once and stops.** **Loop Mode** is **None**. Set it to **Linear** in the library's Advanced Import Settings.
- **Godot warns "Auto Mapping couldn't guess".** For `LeftEye`, `RightEye`, and `Jaw`, this is expected.
