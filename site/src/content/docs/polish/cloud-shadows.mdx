## What you will build

Soft cloud shadows that drift across the meadow with the wind. They fall on the ground, the grass, the flowers, the leaves, the bark, and the bank, all by the same pattern, so a patch of shade crosses a tree and the grass under it as one. The water reflects the same clouds.

It is a small change for how much it adds. One noise texture, three shader globals, one include of about twenty lines, and one added line in each of six shaders.

## How it works

A cloud shadow is a number from 0 to 1 for every point on the ground: 0 in the open, 1 under the middle of a cloud. The shader finds it by reading a noise texture at the point's own position on the ground, shifted a little downwind as time passes. Every shader that finds the number at the same point gets the same answer, so a leaf and the grass under it darken together.

Three things set the look, and each is a shader global so you can change it without touching a shader:

- the noise texture, whose patches are the clouds;
- `cloud_scale`, how many meters the texture repeats across;
- `cloud_strength`, how much light a full shadow takes away.

## The noise

The clouds are a seamless noise, like the ripples in lesson 46 but softer and bigger.

<Steps>

1. In the FileSystem dock make a folder `res://art/clouds`.

2. In the Inspector, open the resource menu and choose **New Resource...**. Search for `NoiseTexture2D` and create it. Set **Width** and **Height** to `512` and turn **Seamless** on, so the texture repeats without a seam.

3. In the **Noise** row choose **New FastNoiseLite**, and open it. Set **Frequency** to `0.012`, and under **Fractal** set **Octaves** to `3`. A low frequency makes big patches and three octaves add a little ragged detail to their edges.

4. Open the resource menu again, choose **Save Resource As...**, and save it as `res://art/clouds/cloud_noise.tres`.

## The include

The shared code goes in its own include, as the wind did.

<Steps>

1. The clouds drift with the wind, so the new include uses `wind_direction` from `wind.gdshaderinc`. A shader that includes both would declare `wind_direction` twice and fail. So first teach the wind include to be included more than once. Open `wind.gdshaderinc` and wrap the whole file in an **include guard**: a `#ifndef WIND_INCLUDED` line and `#define WIND_INCLUDED` at the top, and `#endif` at the bottom. The first time the file is included the name is not yet defined, so the code is used; every later time the name is defined and the preprocessor skips it.

	<Figure
		src={windEditor}
		alt="The Shader Editor showing the top of wind.gdshaderinc with an #ifndef WIND_INCLUDED and #define WIND_INCLUDED above the first comment."
		caption="The wind include, guarded."
	/>

	Save it with <Kbd keys="Ctrl+Alt+S" mac="Cmd+Option+S" />.

2. Choose **File > New Shader Include...**, set **Path** to `res://art/shaders/clouds.gdshaderinc`, and click **Create**. Type the include from the solution below the steps. Its pieces:

	- `#include` of the wind include;
	- the three globals, `cloud_texture`, `cloud_scale`, and `cloud_strength`, each with a comment saying what it is;
	- two constants: `CLOUD_SPEED` `0.5`, the meters a second the clouds drift, and `CLOUD_EDGE` `(0.35, 0.65)`, the noise values where a cloud starts and where it is solid;
	- `float cloud_cover(vec2 world_xz, float time)`, how much of a point is under cloud;
	- `float cloud_shadow(vec3 world_position, float time)`, the light a point keeps.

How the include works:

- **Drift.** `cloud_cover` moves the point against the wind by `time * CLOUD_SPEED` meters, so the pattern slides downwind. `normalize(wind_direction)` keeps the speed the same however the wind's numbers are set.
- **Reading the noise.** The shifted position, divided by `cloud_scale`, is the texture coordinate. The texture repeats, so it never runs out.
- **Soft edges.** The noise value goes through `smoothstep` between the two numbers of `CLOUD_EDGE`. Below 0.35 there is no cloud, above 0.65 it is solid, and between them the shadow fades in. A narrower gap gives hard-edged clouds, a wider one gives mist.
- **The shadow.** `cloud_shadow` is `1 - cover * cloud_strength`: 1 in the open, 0.5 under the middle of a cloud at a strength of 0.5.

## Call it from the shaders

Each shader that draws something under the sky gets one new line, placed after the line that sets its color, so the rim light and anything else that reads the color is darkened with it.

<Steps>

1. Open `ground.gdshader`. Under its includes add `#include "res://art/shaders/clouds.gdshaderinc"`. In `fragment()`, after the line that sets `ALBEDO`, add a comment and `ALBEDO *= cloud_shadow((INV_VIEW_MATRIX * vec4(VERTEX, 1.0)).xyz, TIME);`

	In a fragment shader `VERTEX` is the point in view space, and `INV_VIEW_MATRIX` takes it back to the world. `TIME` is the shader's clock; the include cannot read it itself, so each shader passes it in.

	<Figure
		src={groundEditor}
		alt="The Shader Editor showing ground.gdshader's fragment function: the ground color, then a comment and the ALBEDO multiplied by cloud_shadow."
		caption="The ground shader."
	/>

2. Do the same in `bank.gdshader` (after `ALBEDO = mix(ground, earth, wall);`), `flower.gdshader`, `foliage.gdshader`, and `bark.gdshader`: the include under the other includes, and the line after `ALBEDO` is set.

3. In `grass.gdshader` add the include and the line after `ALBEDO = blade_color;`, and change the next line to `EMISSION = ALBEDO * BOUNCE;`. The blade's own bounce light then takes the shadow too, or the grass would glow in the shade.

## Try it

- Set `cloud_strength` to `0.8` in Project Settings for heavy, stormy shade, or `0.25` for a faint one.
- Set `cloud_scale` to `20` for small, busy clouds, or `120` for slow, wide ones. The texture does not change; it is just stretched.
- Change `CLOUD_EDGE` to `(0.45, 0.5)` for hard-edged shadows, like an overcast sky with gaps.
- Change `wind_direction` in the shader globals and the clouds change direction with the grass.
- Add a script that sets `cloud_strength` with `RenderingServer.GlobalShaderParameterSet` to fade the clouds in and out through the day.

## If it does not work

- **A shader error says "Unknown identifier cloud_shadow".** The shader does not include `clouds.gdshaderinc`, or the file was not saved.
- **A shader error about `wind_direction` being declared twice.** `wind.gdshaderinc` has no include guard, so a shader that includes both it and the clouds include declares the global twice. Add the `#ifndef`, `#define`, and `#endif` lines.
- **No shadows at all.** `cloud_strength` is `0`, or `cloud_texture` is empty: open **Project Settings > Globals > Shader Globals** and check the picker shows the noise.
- **Shadows are a single big dark blotch.** `cloud_scale` is too large for the level. Try a smaller number.
- **The grass glows in the shade.** `grass.gdshader` still has `EMISSION = blade_color * BOUNCE;`. Change it to `ALBEDO`.
- **The water has no clouds.** `cloud_opacity` is `0`, or `cover` in `water.gdshader` still reads the old noise.
